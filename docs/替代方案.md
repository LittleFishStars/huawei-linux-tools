# 替代方案：不等 SDK，今天就能手机↔Linux 传文件

官方 Share Engine 路线的唯一卡点是 `libsharekit.so`（需华为开发者账号下载）。
在等账号/SDK 期间，以下方案都能立刻用，且都走局域网（不耗流量）。

## 方案 A：LocalSend（最接近华为分享的体验）⭐推荐

开源（AGPL-3.0）、跨平台（Android/iOS/Windows/Linux/macOS）、无广告、无需账号、
不依赖任何厂商生态。手机和电脑连同一 Wi-Fi，双方装好即互相发现，点选文件发送。

- Linux：`pacman -S localsend`（官方仓库就有）
- Android：[Google Play / 官网](https://localsend.org) 或国内应用市场搜「LocalSend」
- 协议是 HTTPS REST + 自签证书，速度接近 Wi-Fi 带宽上限

## 方案 B：KDE Connect / gsconnect

功能比文件互传更广：剪贴板同步、通知同步、手机当触控板、媒体控制。

- KDE 桌面：`pacman -S kdeconnect`
- GNOME：装浏览器扩展 GSConnect + `pacman -S kdeconnect`
- Android：Google Play 装 **KDE Connect** app
- 配对：两端同时打开，点配对请求

## 方案 C：SMB 共享（手机「文件管理」原生访问电脑）

华为手机的「文件管理 → 浏览 → 网络邻居」原生支持 SMB。

```bash
sudo pacman -S samba
# 参考 /etc/samba/smb.conf.default 写一个共享段，例如：
#   [share]
#   path = /home/ylxc/Share
#   read only = no
#   guest ok = no
sudo smbpasswd -a "$USER"
sudo systemctl enable --now smb
# 手机：文件管理 → 网络 → 添加网络邻居 → 输入电脑 IP + 账号密码
```

优点：不用装任何手机 app；缺点：只算「手机访问电脑」，反向推送要靠方案 A/B。

## 方案对比

| | LocalSend | KDE Connect | SMB | 华为分享(官方SDK) |
|---|---|---|---|---|
| 体验最接近华为分享 | ✅ | ⚠️ 功能更多 | ❌ | ✅✅ |
| 需要华为账号 | 否 | 否 | 否 | **是（实名）** |
| 手机侧要装 app | 是 | 是 | 否 | 否（系统自带） |
| 剪贴板/通知同步 | 否 | ✅ | 否 | 否 |
| 速度 | 高 | 中 | 高 | 高（80Mbps P2P） |

## 与 NFC 碰一碰的关系

本机 NTAG0001 NFC 芯片的 RF 侧完全自主：手机贴近即触发 irq 并在手机上弹出
`https://consumer.huawei.com/en/support/huaweisharewelcome...` 链接（见
[huawei-ntag0001-nfc](../huawei-ntag0001-nfc) 项目）。但这只是个「欢迎页」NDEF 标签——
真正的分享通道是 BLE + Wi-Fi P2P，与 NFC 无关。也就是说：
**Linux 上有没有华为分享，取决于 Share Engine，不取决于 NFC。**
